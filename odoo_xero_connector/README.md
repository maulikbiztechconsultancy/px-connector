# Xero Odoo Connector

Odoo Xero Connector facilitates you to connect your Odoo with Xero. The module Odoo Xero Connector allows you to easily import as well as export the data for flawless accounting management.

## Features
* Import Taxes
* Import Payment Methods(Journals)
* Import & Export Accounts
* Import & Export Contacts  
 **Note: Xero doesn't support duplicate company names.**
* Import & Export Products
* Import & Export Orders
* Import & Export Invoices(Customer Invoices & Vendor Bills)
* Import & Export Credit Notes (Customer Credit note & Vendor Refunds)
* Import & Export Purchase Orders
* Import & Export Payments

# Flow of Export Order from Odoo to Xero:
Customer, products and taxes added in the order should be mapped.

# Flow of Export Invoice/Bills/Credit Notes/Refunds from Odoo to Xero:
Customer, Products, Taxes and Accounts(account in lines) should be mapped.
